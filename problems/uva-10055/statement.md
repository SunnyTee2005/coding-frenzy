勇士 Hashmat 帶著自己的軍隊與敵軍作戰。每次開戰前，他都想知道雙方兵力相差多少，好決定要不要出兵。

請寫一個程式，算出兩支軍隊人數的差。

## Input

輸入有多行，直到檔案結束（EOF）。每行有兩個非負整數，分別是 Hashmat 軍隊與敵軍的人數（順序不固定，哪一個比較大都有可能）。每個數字都不超過 2<sup>32</sup>。

## Output

每行輸入輸出一行，內容為兩數相差的絕對值。

## Sample Input

```
10 12
10 14
100 200
```

## Sample Output

```
2
4
100
```
