TEX Quotes

The Problem

A typewriter has only one key for the double-quote character ", but a typesetting system such as TEX wants opening and closing quotation marks to look different. In TEX, an opening quotation mark is written as two back-quotes `` and a closing quotation mark is written as two apostrophes ''.

Write a program that converts plain text into TEX style. The first " in the text opens a quotation, the next one closes it, the one after that opens a new quotation, and so on. Quotation marks are paired across the whole input, not line by line.

Input

The input is a block of text that may contain any printable characters and an even number of double-quote characters. It ends at end of file.

Output

Print the text exactly as given, except that every " is replaced by `` or '' as described above.

Sample Input

She said "hello" and
then "walked
away" quietly.

Sample Output

She said ``hello'' and
then ``walked
away'' quietly.
