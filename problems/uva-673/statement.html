Parentheses Balance

The Problem

A string made only of the characters (, ), [ and ] is called correct if:

  1. it is the empty string, or
  2. it is the concatenation of two correct strings A and B, or
  3. it has the form (A) or [A] where A is correct.

Decide for each given string whether it is correct.

Input

The first line contains a positive integer n, the number of strings. Each of the next n lines contains one string of length at most 128. A string may be empty, in which case its line is empty.

Output

For each string, print Yes if it is correct and No otherwise, one answer per line.

Sample Input

4
[()]
([)]
(([])[])

Sample Output

Yes
No
Yes
Yes
