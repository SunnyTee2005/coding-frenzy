Primary Arithmetic

The Problem

When children first learn to add multi-digit numbers column by column from right to left, the hardest part is the carry: when the digits of a column add up to 10 or more, a 1 is carried into the next column. Teachers would like to know how many carry operations each exercise contains so that they can judge how difficult it is.

Given two numbers, count how many carry operations happen when they are added.

Input

Each line contains two unsigned integers with fewer than 10 digits. The last line contains 0 0 and must not be processed.

Output

For each line except the last, print the number of carry operations in exactly one of the following forms:

No carry operation.
1 carry operation.
n carry operations.

Sample Input

321 456
37 85
5 999
0 0

Sample Output

No carry operation.
2 carry operations.
3 carry operations.
