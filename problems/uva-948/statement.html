Fibonaccimal Base

The Problem

Use the Fibonacci numbers 1, 2, 3, 5, 8, 13, 21, ... (each one is the sum of the two before it) as the place values of a number system. Every positive integer can be written as a sum of distinct Fibonacci numbers in which no two consecutive Fibonacci numbers are used. This representation is unique and can be found greedily: repeatedly take the largest Fibonacci number that does not exceed what is left.

Write the representation as a string of 0s and 1s, with the digit for the largest Fibonacci number used on the left and the digit for 1 on the right. For example, 11 = 8 + 3, so it is written 10100.

Input

The first line contains an integer N, the number of test cases. Each of the next N lines contains one positive integer smaller than 100 000 000.

Output

For each number x, print one line in the form x = representation (fib).

Sample Input

4
11
1
7
20

Sample Output

11 = 10100 (fib)
1 = 1 (fib)
7 = 1010 (fib)
20 = 101010 (fib)
