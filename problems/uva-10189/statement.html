Minesweeper

The Problem

In the game Minesweeper, a rectangular field hides some mines. Every square that is not a mine shows how many mines are in the up to eight squares that touch it (horizontally, vertically or diagonally).

Given a field in which mines are marked, produce the hint numbers for every safe square.

Input

The input contains several fields. Each field starts with a line with two integers n and m (0 < n, m ≤ 100), the number of rows and columns. The next n lines each contain exactly m characters: * for a mine and . for a safe square. A line with 0 0 ends the input and must not be processed.

Output

For field number x (starting at 1), print the line Field #x: followed by the n rows of the field, with every . replaced by the number of adjacent mines and every * left unchanged. Print an empty line between two consecutive fields.

Sample Input

3 4
*...
..*.
....
2 2
.*
*.
0 0

Sample Output

Field #1:
*211
12*1
0111

Field #2:
2*
*2
