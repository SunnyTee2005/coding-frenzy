# CPE 考試環境研究筆記

> 本專案是**非官方**的 CPE 模擬考試環境，與 CPE 委員會、中山大學、瘋狂程設作者均無關。
> repo 內不放官方程式、反編譯原始碼或官方截圖；這份文件只記錄觀察結果。
> 參考資料（官方 PDF、原程式、截圖）請放在本機的 `research/`（已列入 .gitignore）。

## 1. 考場軟體：瘋狂程設 CodingFrenzy（CodingFrenzy@CPExam）

- 自 2013/10/1 起，CPE 改用「瘋狂程設」評判系統。作者是阿平（coding-frenzy.arping.me）。
- **只支援 Windows**，依賴 Microsoft .NET Framework 2.0（WinForms）。
- 考生機安裝方式：下載 `CodingFrenzy@CPExam.zip`，解壓到 `C:\CodingFrenzy@CPExam`，執行 `CodingFrenzy.exe`。
- 編譯器要另外安裝，而且必須在**預設路徑**，瘋狂程設才會自動抓到；改路徑就找不到。CPE 官網的協辦專區有自動安裝程序檔。
- 練習時用「瘋狂程設帳號」，正式考試用「CPE 帳號」，兩者不同。

### 考場語言（environment.php，2021/10 安裝包）

| 語言 | 版本 |
|---|---|
| C/C++ | MinGW GCC 6.3.0 |
| C/C++ | MSVC v140 |
| Java | AdoptOpenJDK 8、AdoptOpenJDK 11 |
| Python | Python 3.9.6 |

硬體需求：19 吋以上螢幕、雙核 2GHz、4GB RAM、Windows 7 以上。

## 2. 考試流程（考生視角）

1. 啟動程式 → **同意授權規定** → 連線到伺服器（伺服器依考生簽到表分配）。
2. **登入**：輸入身分證字號、准考證號碼。
3. 主畫面：**考生功能**、**現在時間**、**考試題目列表**。
4. 題目列表每題有 **「看題」** 和 **「解題」** 兩個按鈕。看題不計時；按「解題」後題目才開啟、開始計時（考生心得的說法）。
5. 解題視窗（綜合多篇描述，待 Phase 0 以原程式確認）：
   - 最上方是**工具列**。
   - 最左邊是 **「批改交卷」**，也就是正式評判，按下會跳出確認視窗。
   - 右側有三個測試按鈕：**題目預設測試資料**、**自訂測試資料**、**人工公開測試資料**。
   - 中間是題目，題目下方寫程式。
   - 右半部顯示編譯結果與範例輸入輸出。
   - 快捷鍵：**Alt+L** 選擇編譯器，**Alt+J** 觀看評判結果。
   - 編譯器選單的項目字串例如 `CCPP:MinGW`。
6. 三種測試都**不列入成績**：
   - 題目預設測試資料：系統產生，難度較低。
   - 自訂測試資料：考生自行輸入。
   - 人工公開測試資料。
7. **正式評判**用不公開的「暗中測試資料」，結果列入正式紀錄，並顯示在所有考生的成績表上。
8. 結果狀態：`CORRECT`、`WRONG-ANSWER`、`PRESENTATION-ERROR`、`COMPILER-ERROR`（點連結可看編譯器錯誤訊息）、`RUN-ERROR`、`NO-OUTPUT`，以及等待中。
9. **考生功能**：成績表（觀看所有考生正式考題的成績）、考生手冊（考生機桌面「考生功能\考生手冊」）。
10. 有**線上字典**可查英文單字（考生心得）。

## 3. 考試規則

- 7 題：3 題一顆星、2 題二顆星、1 題三顆星、1 題四顆星。題目來自 UVa Online Judge。
- 考試時間 3 小時，例如 18:40–21:40，19:40 後可離場。
- **計分採 ICPC 制**：
  - 先比答對題數，同題數再比解題時間總和。
  - 每題的時間 = 從開考到答對的分鐘數 + 每次錯誤提交 × 20 分鐘。
  - 沒答對的題目不計時間與罰時。
  - 官方範例：10 分答對 A；15 分 B 錯誤、32 分答對 B → 10 + 32 + 20×1 = 62。
- 成績報告有兩種成績：「絕對成績」依答對題數分級，「相對成績」依 ICPC 排名。成果報告中有各題數的累計百分比。

## 4. Phase 0 結果（2026-10，從官方鏡像站 cpe.mcu.edu.tw 與 coding-frenzy.arping.me 取得）

畫面細節見 [ui-spec.md](ui-spec.md)。

### 已確認

- [x] **版面、標籤、選單、快捷鍵、對話框**：依《考生使用手冊》2023/11 的截圖整理在 ui-spec.md。手冊已涵蓋授權、登入、主畫面、考生功能選單、解題視窗全部選單、批改確認、存檔/提檔、成績表。
- [x] **結果字串**（手冊 1.5）：CORRECT、WRONG-ANSWER、PRESENTATION-ERROR、COMPILER-ERROR、RUN-ERROR、NO-OUTPUT、**TIMELIMIT**、**PENDING**。
  - 逾時的字串是 `TIMELIMIT`，不是 `TIME-LIMIT-EXCEEDED`。
- [x] **編譯指令**：
  - CCPP:MinGW 是 `g++ -O2 -lm -static-libgcc -static-libstdc++ -Wl,-Bstatic -lstdc++ -m32 -omain.exe main.cpp`。
  - **C 程式也存成 main.cpp、用 g++ 編譯**。
- [x] **Python**：沒有編譯步驟，直接 `python main.py`。語法錯誤會在執行階段出現，不是 COMPILER-ERROR。
- [x] **正式評判**：確認視窗寫明「批改錯誤將罰扣20分鐘」。
- [x] **成績表**：
  - 每題格式是 `次數(分鐘+罰時)`；「耗時」只加總答對題，每 5 分鐘更新。
  - 範例中解 5 題、2 題錯誤的考生總耗時 17 分，可見未解題的罰時不計。
- [x] **時段**：
  - 18:30 前看得到練習題；18:30~18:40 封鎖；18:40~21:40 正式考試。
  - 18:00 後不准入場，19:40 後才可離場。
- [x] **英漢字典**：在考生功能選單裡。手冊說明：「題目中的英文單字無法直接複製貼上」。
- [x] **一顆星選集 49 題清單**：CPE 編號與 UVa 編號的對照見下方 §5。
- [x] **成績分布**：見下方 §6。

- [x] **計時**（考生注意事項七、考試規則十二）：解題時間是「考試開始至解題正確所經過的時間」，以分鐘為單位。
  - 考試共 3 小時，題目可以任意開、任意順序作答。
  - 「看題」「解題」只是開啟方式，不影響計時。
- [x] **題目順序**（考生注意事項三）：「考題中，經研判比較簡單的三題，編排為前三題。」
- [x] **題庫方向**：使用者決定以 **CPE26 選集**為主（2027 年起每次考試有一題出自這裡）。

### 仍待確認

- [ ] **比對規則細節**（行尾空白、檔尾換行）：
  - 官方文件只寫到 PRESENTATION-ERROR 是「多空格或少空格，多換行或少換行」，以及「若輸出的格式產生過大錯誤，也可能造成 WRONG-ANSWER」。
  - 考試規則只說題目採 ICPC 格式、取自 UVa。
  - UVa 官方的 verdict 說明同樣沒寫明。
  - 實際比對在 `FrenzyBat.exe score`（原生 C++，使用 std::regex），可讀字串只有 `TIMELIMIT`、`@same`；要再深入就得反組譯，所以停在這裡。
  - **目前採用類 UVa 的嚴格規則**：
    - 只寬容 CRLF 與檔尾換行。
    - 行尾多一個空白、多或少空行都算 PRESENTATION-ERROR。
    - 內容不同算 WRONG-ANSWER。
  - 使用者若找到明文規定，再調整 `crates/judge/src/compare.rs`。
- [ ] **COMPILER-ERROR 是否罰時**：考試規則寫「被評判為錯誤的次數乘以 20 分鐘」，沒有排除編譯錯誤。目前不罰（ICPC 慣例），待確認。
- [ ] **預設時限**：沒有找到，暫定每題 3 秒（UVa 常見值），依題目 meta 設定。
- [ ] **Python 在編譯器選單中的字串**：推測是 `PYTH:Python39`，沒有截圖。
- [ ] **主程式中被加密的字串**（LibFrenzy.dll 的介面文字與訊息）沒有解開。
  - 原因：解碼需要執行外部程式碼，被環境的安全規則擋下。
  - 目前用手冊截圖代替。

### 原程式結構（觀察結果）

- `CodingFrenzy.exe`（v3.1123）是 .NET 2.0 的小型啟動器。
  - 它把 `CodingFrenzy.cpk` / `.spk` 解開到 `CFData\Archive\…`，再載入 `LibFrenzy.dll` 的 `WFMain`。
- `.cpk` / `.spk` 是修改過檔頭的 7z 壓縮檔：開頭 6 個位元組由 `7z\xBC\xAF\x27\x1C` 改成 `arping`。
- `.spk` 的 `main.cfg` 內容：
  - `軟體名稱=大學程式能力檢定`、`軟體型態=檢定`。
  - 伺服主站是 `https://cpe01~05.arping.me/cert`。
- 主畫面是嵌入 IE 的網頁。解題視窗用 DockPanel Suite 排版，編輯器是 Alsing SyntaxBox。
- 評判結果面板是 HTML 範本 `FrenzyBat/template.htm`。
  - 狀態 CSS class 就是結果字串本身。
  - 「通過」：紅底黃字；「未通過暗中測資」：黑底黃字。
- 啟動時會要求把資料夾加入 Windows Defender 排除清單。

### 題庫收錄狀況（2026-10）

共 188 題，每題都通過兩道檢查：標準解跑過全部測資（`cpe-judge verify`），以及另外寫的 Python 解法逐筆比對答案（`tools/crosscheck/`）。

- **CPE26 選集**：51 / 56 題。
- **近十年（2016 起）考古題**：164 / 280 個不同題目。其中前三題（P1~P3）收錄 114 / 117 題。
- **可以整場重考的場次**（7 題全部收錄）：2023-03、2023-05、2024-04、2025-03、2025-05、2026-03。
- 其他 2023 年後的場次大多只差 1~2 題，見下方未收錄清單。

**題意來源**：
- 能從 CPE 鏡像站下載 PDF 的題目，都依原文撰寫，並用原文範例核對。
- 鏡像站沒有 PDF、沙箱又連不到 onlinejudge.org 的題目（例如 111、297、340、417、442、573、580、665、907、941、1062、1118、1193、1203、1292、10125、10154、10229、10405、10443、10539、10672、10858、11518、11526、11806、12015、12063），是依我對 UVa 原題的了解撰寫：
  - 只收錄能把記得的官方範例輸出完全重現的題目。
  - App 執行時仍會下載原文 PDF 給考生看。

**為了避開題意不明的地方，測資刻意不出的情況**：

| 題目 | 不出的情況 | 原因 |
|---|---|---|
| 10150 | 最短路徑不唯一的詢問 | 題目允許輸出任一條，但判題是逐字比對 |
| 828 | 可以有兩種解讀的密文 | 同上 |
| 13242 | 最佳溫差平手 | 平手規則沒寫清楚 |

| 10101 | 輸入 0 | 輸出格式沒定義 |
